## 3. 来源与真实凭据（无 Key 时明确记为阻塞）

需要用户自己的、适用于实际调用方式的天地图凭据。当前实现没有创建、借用或内置他人 Key。

- 同源模式：`.env.local` 配置 `TIANDITU_TOKEN`，使用允许服务端 WMTS 调用的授权，重启服务。
- 纯静态模式：`VITE_DIRECT_TILES=true`，另配允许网页公开的浏览器端 `VITE_TIANDITU_TOKEN`，配置真实域名白名单并重新构建。
- 核对天地图控制台的产品权限、配额、当前服务条款、署名/标识和发布条件；不能把“填写了 Key”当作授权已经验证。

- [ ] 核对官方 WMTS 文档或 GetCapabilities：`vec_w` / `cva_w` / `img_w`，`TILEMATRIXSET=w`，256 像素、当前配置 z1–18。若官方矩阵和权限支持范围不同，更新客户端及服务端相同的上下限。
- [ ] 只检查少量固定当前视图，确认 HTTPS、正确 Key 类型、实际 Referer 下可返回图像；记录类型/大小/耗时但隐去完整带 Key 的 URL。
- [ ] 中国网络优先且有 Key：街道为 `tianditu-vec`＋`tianditu-cva`；卫星为 `tianditu-img`；自动在 25 km 以下选街道，其余选影像。没有 Key 时明确提示并使用原全球来源。
- [ ] 全球模式维持原 OSM / EOX / GSI / USGS / 可选 ArcGIS 行为。中国网络优先与相机是否看中国是不同概念，浏览海外时也要核对天地图覆盖情况。

## 4. 排队、清晰度与恢复

主要文件：`src/layers/ImageryTileLayer.ts`。

- [ ] 首次视图先请求必要的 z−3 父级（钳制到来源最小级别），随后按屏幕中心优先请求最终层级；不先下载全部中间层，不额外扫图或预取邻域。
- [ ] 已有目标瓦片时不重新请求不需要的父级；平移后重算中心优先级。父图在子图渐入的 280 ms 内持续覆盖。
- [ ] 天地图底图就绪后可立即绘制，路名单独排队；所有请求共用 4/8 个名额，注记不能把并发翻倍。部分注记失败只影响路名状态，不抹掉底图。
- [ ] 正常图像请求 12 秒、慢网 20 秒、USGS 35 秒上限；超时计入失败、释放名额并保留原图，主动取消不计入供应商失败。
- [ ] 连续 4 次底图失败或 401/403/429/明确拒绝触发冷却，取消旧来源余下请求，切换已配置的兼容备用源。卫星不能悄悄改成街道。
- [ ] 备用源生效后保持稳定，不在原源每个冷却周期到期时自动往返跳转；切换模式/网络配置或手动重试可重新评估，但不绕过 Retry-After。
- [ ] 无备用来源或全部失败时，保留已加载地图及 NASA 底图，状态不能谎报“高清已就绪”。冷却结束后允许恢复。
- [ ] 断网立即停止新请求，取消进行中请求，恢复网络后重新排队。快速拖动、缩放、连续切换来源、销毁时 Bitmap、纹理、计时器和 pending 计数正确释放。
- [ ] 600 m、150 m、4K / DPR 3 保持原定高分辨率、无数量截断。使用 `scripts/selection-audit.mjs` 复核大视口数学覆盖。

## 5. 同源服务

主要文件：`server/tile-relay.mjs`、`server/tile-transport.mjs`、`server/serve.mjs`、`vite.config.ts`。

- [ ] 同一瓦片的并行请求只向上游下载一次；第一个客户端取消但其他客户端仍等待时不取消共享请求，最后一个客户端离开时取消。取消后的新请求不能接到已中止的旧任务。
- [ ] 不同条件请求不能混用无正文 304；304 合并缓存头、Age/Date 更新、ETag/Last-Modified 重验证及浏览器缓存行为正确。
- [ ] `s-maxage` 优先于 `max-age`；`no-cache` 必须重验证，`no-store` / `private` 不进入共享缓存。304 改为 no-store/private 后移除旧缓存。
- [ ] 64 MiB 缓存只淘汰不再命中的响应，不改变 LOD；不创建磁盘离线地图。
- [ ] 429 的秒数/日期 Retry-After、401/403、x-blocked 拒绝图、200 JSON/XML 错误均不能铺到地图上。冷却期间不继续请求该服务，也不轮换域名来规避拒绝。
- [ ] 某并行请求成功不能清除另一个请求刚触发的服务端冷却；手动刷新/重试也不能跳过冷却。
- [ ] `X-Earth-Cache`、`X-Earth-Error`、`Server-Timing` 不包含 token 或 URL。白名单/坐标范围/非 GET-HEAD/畸形 URL/继承属性名不得成为任意 URL 转发。
- [ ] Vite dev、preview 和 `npm run serve` 都提供配置接口和相同瓦片链路；默认根路径部署可用。若实际要部署到子路径，单独检查 BASE_URL 与转发路由挂载，不假设已支持。
