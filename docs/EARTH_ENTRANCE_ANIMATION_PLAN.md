# 地球入场动画实施方案

> 状态：2026-10-04 基础动画及后续光照同步修复、节奏调整均已实现，待验证。从遮罩退场到动画结束约 2 秒（含约 0.2 秒显露时间），采用快到慢缓出、40° 倾角与共同旋转的有效光照方向。本轮未运行构建、测试或浏览器验收。

## 视觉定义

1. 动画只在首次加载完成后播放一次。加载期间不显示未完成的地球；基础地球资源准备好后，先以约最终尺寸的 10%–15% 在画面中央出现。
2. 背景星空和 UI 保持稳定。地球沿倾斜方向转入默认朝向，旋转幅度约 40°，同时放大至 100%。
3. 从遮罩开始退场到动画结束约 2 秒：保留现有约 0.2 秒小地球显露时间，之后约 1.8 秒放大并转向。速度由快到慢并平滑停稳；不做夸张弹跳。结束后再开放拖拽/缩放等交互，并恢复项目既有的自转状态。
4. 尊重 `prefers-reduced-motion`：减少动态偏好时直接显示最终状态。

数值是实现起点，最终观感以不晕、不突兀、地图纹理稳定为准。这里的“斜着旋转”指绕倾斜轴转到默认朝向，不是从屏幕角落沿对角线飞入。

## 昼夜分区错位：问题分析与修复方案

### 问题是什么

现有地球入场把 `globe` 父组从约 28° 倾斜旋回默认四元数，但太阳方向保持在场景/地理坐标中不动。`EarthMaterial`、云层和大气 shader 使用世界空间法线，并与固定的 `SunLightController.direction` 点乘。父组旋转时，地表法线随地球转、太阳方向不转，昼夜分界就会相对贴图滑动，看起来像地球和黑白天区各自旋转。

在线影像瓦片 shader 当前使用局部法线，却读取同一个场景空间太阳方向；应一并统一坐标空间，避免基础贴图和在线影像的昼夜边界出现不同步。

### 修复方式

1. 保留 `SunLightController.direction` 作为真实/模拟太阳方向，不在动画中改写这份物理方向。
2. 新增一个供所有受光材质共用的有效太阳方向。动画播放时，每帧用当前地球父组四元数旋转太阳方向：`effectiveSunDirection = globe.quaternion × sun.direction`。地表、在线瓦片、云层和大气统一用世界空间法线与此方向计算受光。
3. 这样法线和太阳方向同乘相同旋转，二者点积保持不变；在 canonical 太阳方向未变化时，昼夜边界、城市夜光与云层日照固定于纹理。海面反光和大气也使用同一有效太阳方向，但高光、Fresnel 和大气边缘仍保留正常的视角相关变化，不能把高光位置完全静止作为验收标准。
4. 动画结束时先将父组四元数精确设为单位值，再把有效太阳方向切回当前太阳方向。此时两方向数值相同，光照无跳变，并恢复原有实时/模拟光照更新。
5. 覆盖实时太阳、预设时刻、减少动态直接结束、后台暂停/续播、上下文丢失和销毁路径。清理动画期间的每帧光照覆盖，不残留到搜索、缩放或后续用户操作。

## 当前项目适配与实施步骤

1. **新增轻量动画依赖**：使用 `gsap` 核心包，并锁定兼容当前 Vite/TypeScript 的稳定版本；不引入 `globe.gl`，不替换 `EarthRenderer`。
2. **找到准确触发点**：在 `EarthRenderer.initialize()` 完成、当前本地地球材质和 WebGL 场景已就绪时触发；不要等待中国网络下的远程细节瓦片全部加载。初始加载遮罩开始退场时，地球已经处于小尺寸，避免先闪出完整尺寸再缩小。
3. **整体变换而非逐个球体变换**：当前地表、在线瓦片、云层、大气层和经纬网分别挂在场景里。建立一个只承载地球视觉图层的父级 `Group`，让相关图层一起缩放/转动，结束时父级恢复单位缩放和默认朝向。不要改变 WGS84 坐标、相机高度定义、瓦片数据、投影或纹理本身。
4. **标记与交互同步**：检查 `MarkerLayer` 中屏幕投影标签与地球父级旋转的关系；入场期间暂不显示/更新容易错位的地点标签，完成后立即恢复。入场期间避免用户拖动与自动相机控制争抢，完成回调中恢复正常交互和原定自转。
5. **GSAP 时间轴**：缩放与倾斜转向同时进行，起始 scale `0.10–0.15`，最终 scale `1`，倾斜转角约 `40°`。从遮罩开始退场到结束总计约 `2s`，保留 `0.2s` 显露后，缩放/转向约 `1.8s`。使用 `power2.out` 一类快到慢缓出曲线，平滑停稳且不 overshoot。具体起始 Euler/quaternion 按默认地球朝向校准，最终 transform 必须精确归零/单位值，以免地理标记偏移。
6. **生命周期与无障碍**：页面切后台时动画暂停或安全完成；组件销毁时 kill timeline，不能在已释放的 renderer 上继续写属性。减少动态偏好时跳过时间轴，直接置最终状态。
7. **保持范围**：不调整资源加载策略、中国网络线路、瓦片供应商或 LOD；不播放到搜索飞行、重置或切换地点等后续操作；不重复播放。
8. **锁定昼夜分区**：为所有日照相关 shader 使用统一坐标空间和同一有效太阳方向；入场期间将太阳方向与 `globe.quaternion` 同步变换，结束时在单位姿态下无跳变地还原太阳方向。不得通过旋转纹理 UV 或修改真实太阳方向来掩盖错位。

## 验收标准

- 首次主地球资源加载完成后，地球从中央小尺寸倾斜转入并平滑放大；没有完整尺寸闪帧或白屏。
- 从遮罩开始退场到动画结束约 2 秒（显露约 0.2 秒、转动/放大约 1.8 秒），速度由快到慢平滑停稳，倾斜约 40°；星空背景保持稳定。
- 在倾斜转动过程中昼夜边界相对地表纹理保持固定；地表、在线瓦片、云层和大气的日照及夜光保持一致，入场结束时恢复当前太阳方向且没有亮暗跳变。
- 地表、瓦片、云层和大气视觉变换同步；结束时地球姿态与默认朝向一致。
- 动画期间标签不漂移，结束后地点定位、WGS84 标记、瓦片 LOD 与相机输入继续工作。
- 交互和既有自转只在入场结束后恢复；二次打开面板/搜索/选地点不重新播放。
- `prefers-reduced-motion` 下无入场动画但页面立即可用；切后台或销毁场景不会留下运行中的 tween。
- 此次实现未执行构建、测试或浏览器验收；下方记录为代码实施说明，验收结果另行记录。

## 2026-10-04 实施记录

> 下列条目记录第一次基础动画实现，其中 28° / 1.55 秒为历史值；现行参数及光照修复见后续实施记录。

- 安装并精确锁定 `gsap@3.15.0`，同步 `package.json` 和 `package-lock.json`；仅使用 GSAP 的普通对象补间和时间轴，没有引入 globe.gl 或额外动画插件。采用官方 [Timeline](https://gsap.com/docs/v3/GSAP/Timeline/) 的并行编排、暂停/恢复与取消能力。
- `EarthRenderer` 新增地球视觉父组：地表、在线瓦片、云层、大气和经纬网一起变换。星空仍直接挂在场景上，相机位置和地球中心不参与入场变换。
- 本地基础资源就绪后，在首次渲染前准备 0.12 倍缩放与 28° 倾斜转角。倾斜轴相对相机方向定义；初始加载遮罩用 0.2 秒退场，时间轴保留这段小地球展示时间，再同时进行 1.35 秒的缩放与转向，使用 `power2.out`，总时长约 1.55 秒。
- `App` 在本地 `initialize()` 返回后调用一次 `playEntrance()`，不等待远程瓦片。动画完成前 `ready` 为 false，相机相关按钮暂不可用；结束后恢复可用状态与原有自转偏好。搜索、重置及后续地点飞行不会重播入场。
- `CameraController.setSuspended()` 同时暂停 OrbitControls、逐帧相机运动、自定义滚轮/双指及程序化缩放/飞行入口，不改写原有相机高度、投影和飞行算法。入口暂停不覆盖原先的自转偏好。
- 入场期间地点标签隐藏且不逐帧更新，云层独立漂移暂停。结束时父组缩放精确设为 1、四元数精确设为单位值，再恢复标签投影和相机操作。
- 减少动态偏好下直接显示最终状态；播放中启用该偏好会结束动画并停止自转。页面进入后台时暂停时间轴，返回后续播；若本地资源在后台完成，时间轴保持暂停直到回前台。
- 销毁或 WebGL 上下文丢失时取消时间轴并清除完成回调；销毁时解除动态偏好和可见性监听。上下文丢失仍走已有的重新载入错误入口。
- 未改变地图网络、来源、瓦片选择/请求、纹理质量或 WGS84 数据。GSAP 可以与现有生命周期协作，因此未使用自写补间替代方案。

实施期间只执行依赖安装（禁用安装脚本）与改动文件格式化，未运行任何测试或构建。首帧表现、同步效果、交互恢复及资源释放仍需验证，完整任务见 [EARTH_ENTRANCE_SOL_TESTS.md](./EARTH_ENTRANCE_SOL_TESTS.md)。

## 2026-10-04 后续修复实施记录（已实现，待验证）

- `src/earth/EarthRenderer.ts`：初始姿态和时间轴统一改为 40°，并行缩放/旋转时长 1.8 秒，起点仍为 0.2 秒，缓动保持 `power2.out`；12% 初始尺寸不变。
- 新增独立的 `effectiveSunDirection`，初始化时复制 canonical 方向。地表、在线瓦片、云和大气的 uniform 全部引用同一个有效方向对象；每次 `composer.render()` 前复制当下 canonical 方向，再应用当前 `globe.quaternion`。GSAP 不单独更新光照，没有第二个逐帧光照计时器或回调。
- `src/earth/EarthMaterial.ts`：明确材质参数是共享的世界空间太阳方向；地表日照、夜光、海面反光及云层使用该 uniform，原有世界空间法线、世界位置与 UV 保持原样。
- `src/layers/ImageryTileLayer.ts`：将瓦片顶点法线经 `mat3(modelMatrix)` 转换并归一化后传入 `vNormalWorld`，片元日照/夜光计算也采用世界空间。当前对象只有平移、旋转和均匀缩放，与基础地表采用相同法线变换；投影、瓦片请求和纹理坐标不变。
- 完成和取消路径共用 `resetEntrancePose()`：先设置单位缩放/单位四元数，再复制当前 canonical 方向并更新矩阵。正常完成及减少动态直接完成随后恢复标签/交互；上下文丢失或 dispose 只取消时间轴和复位，不触发完成回调。
- 后台仍暂停 GSAP 和渲染循环，返回后在首次绘制前重新同步有效方向。正常入场结束后父组保持单位姿态，每帧复制太阳方向，实时太阳和模拟时刻继续沿用 `SunLightController` 的更新方式，不改写 canonical 数据。
- 本轮没有修改相机、网络、供应商或 LOD；没有旋转 UV。仅做代码/文档调整及格式化，未运行构建、测试或浏览器验收。待验证项见 [EARTH_ENTRANCE_SOL_TESTS.md](./EARTH_ENTRANCE_SOL_TESTS.md)。
