## 实施记录

搜索名称已替换为 `troika-three-text@0.52.5` 的真实 Three.js SDF 文字；依赖精确锁定，peer 范围 `three >=0.125.0`，在项目 Three.js 0.183.2 上完成构建与浏览器检查。删除旧名称 DOM、容器和 CSS，仅保留一个文字对象，按 WGS84 经纬度放在当地东—北切平面；位置和朝向不随镜头重设。使用地表上方 2 m、深度测试和 polygon offset，保留地球遮挡，不通过禁用深度或朝镜头抬高冒充贴地。

旧版连续缩放 158 帧实测发现整数 `offsetWidth` 与实际小数宽度的居中差，最大 0.25 CSS px，跨整数时出现跳变；这是已确认的一项抖动来源，不宣称解释全部视觉抖动。新版固定文字排版和地理中心，由相机透视缩放，渲染前刷新相机矩阵并更新透明度，不逐帧测 DOM/改字号。极近处连续缩放到最大 34 px，长名称按可用视口宽度连续限制。继承真实飞行最后 1/3 渐显、到达停留 3000 ms/淡出 500 ms、缩放保留原截止时间、替换/飞行取消/重置/销毁/后台清理及减少动态。

用户后续反馈“字体不明显”：到达字号由本轮初版 20 px 提高至 **24 px**，白灰填充增加约 **0.96 px 清晰深色描边**（0.04 em，blur=0），填充和描边同步淡入淡出；不添加底框、光晕或新动画。文字仍保持原来的地理方向与衬线字体。

字体来自本地 Cinzel 400 与实际 Source Han Serif SC 400。大型 CFF OTF 试验被 Troika 解析器拒绝，改用 Adobe 官方 SC TrueType 可变字体实例化为 400，再封装 WOFF，浏览器成功载入。中文派生字体按 OFL 保留名称规则改名 Earth CJK Serif；剔除 Cinzel 已覆盖字符，防止混排时英文落入中文字体。抽查 17 个中文字形，坐标、轮廓端点及标记与官方 SC 400 序列化结果完全一致；两字库 cmap 无重叠。字体、完整许可、来源、重建脚本说明和校验值见 [字体说明](../public/fonts/README.md)。启动时预热常见城市/字母/数字；异步结果按 generation 丢弃，材质/几何释放；字体失败时不显示名称、不阻塞定位。未覆盖字符明确显示本地缺字方框，不请求 Unicode 字体 CDN。

## 目标与范围

用户观察到现有名称缩放抖动、地表绑定观感不佳，确认更换搜索选中后地球上的名称实现：英文 Cinzel，中文思源宋体 Source Han Serif SC。搜索框、结果列表、按钮等字体不改；不添加城市边界。

优先采用 troika-three-text 的真实 Three.js 文字对象，替换 HTML 名称投影。保留自定义 WGS84 地球、现有相机与飞行；不整体迁移到 three-globe。参考：https://protectwise.github.io/troika/troika-three-text/ 。核对与当前 Three.js 的兼容版本并锁定依赖。

## 呈现要求

- 每次搜索最多一条文字，锚定城市经纬度，中心随字体准备/字号变化不漂移；沿当地地表切平面摆放，保持地理方向，不能每帧始终转向镜头冒充贴地文字。
- 通过相机透视自然缩放，避免每帧测量 DOM 或改字号造成抖动。先排查现有抖动，记录真实原因；不要未经证据声称原因已确定。与地表/瓦片保持合理间距和深度处理，避免 z-fighting、悬空、背面透出或被云层错误遮盖。
- 白灰、常规/适中笔重、略宽字距，无底框、圆点、光晕或副标题。仅地表名称换字体。中文字形实际使用思源宋体 SC，不能仅写 font-family 而回退到系统字体；混合中英文、长名称及坐标表达需正常。
- 延续飞行最后约三分之一由真实进度驱动渐显，到达时可读，停留约3秒后约0.5秒淡出。早期自然小而透明，不增加独立弹跳/放大动画。极远可隐藏，极近避免过大遮盖，缩放策略保持连续。
- 字体随项目本地分发并附许可，优先预热常见城市与必要字形，避免飞行中缺字、换字体或异步旧结果覆盖新搜索。Troika 支持 TTF/OTF/WOFF，官方文档说明不支持 WOFF2；中文缺字回退要考虑离线与Android内置资源，不能暗中依赖外部字体CDN。
- 保留减少动态、替换、取消、重置、销毁、后台过期的行为；异步字体处理与纹理/几何释放要正确。
