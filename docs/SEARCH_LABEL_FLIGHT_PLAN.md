## 已确认的视觉效果

- 选中城市后，名称锚定到真实经纬度，不在地表漂移。随地表投影移动与透视缩放，远时小、近时大；不是固定字号的屏幕提示。
- 飞行开始时名称很小、接近透明；飞行最后约三分之一逐渐淡入，到达时清晰可见。大小变化来自相机与地表距离，不另做弹跳或独立放大动画。
- 到达后完整显示约 3 秒，再约 0.5 秒淡出；用户继续缩放时仍随地表缩放。极远时淡出，极近时限制最大尺寸避免遮盖地图，主要飞行范围内保持自然等比例关系。
- 仅显示一行白灰名称，无底框、圆点、光晕、英文副标题或边界。目标在地球背面、视口外或与关键控件冲突时隐藏，不贴到视口边缘。
- 减少动态模式下定位完成后直接显示，不做渐变或独立动画，保留短暂显示和清理。

## 实现范围

1. 复用现有 SearchLabelLayer、经纬度投影和相机飞行状态。可以用投影计算缩放或地表文字渲染，只要满足锚定、遮挡、清晰度与小范围修改，不引入新地图数据或重构整个渲染器。先判断现有 DOM 投影能否完成需求。
2. 淡入由真实飞行进度驱动（建议约 0.67→1 用平滑曲线映射到透明度），不靠独立 timeout 猜测到达。飞行较短、无位移、目标初始背面或从近处飞往远处也要保持自然，到达时可读；到达后再启动 3 秒停留计时。
3. 文字锚点不随字号变化漂移，不新增向上滑入效果。城市名安全写入；坐标查询保持紧凑坐标，长名称保持合理可读布局。最小字号不强迫远处文字可见，允许自然缩小并淡出。
4. 保留同时最多一条名称，以及连续搜索替换、飞行取消、拖动/重置、销毁和后台过期清理。不得残留旧名称或回到前台重新播放过期标签。
5. 不改变相机飞行路径/速度、自转减半参数、搜索结果、加载轨道动画、Logo、原生 Android 启动、地图网络与瓦片算法。
