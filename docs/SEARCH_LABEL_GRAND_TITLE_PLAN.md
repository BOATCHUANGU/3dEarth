# 地表地点大标题与浅香槟金

2026-10-14。用户确认按红圈所示显著放大地点文字，采用首选浅香槟金，由 Sol 实现、Luna 更新文档。**设计阶段**用户要求本轮不进行 Git 提交、推送、tag、GitHub Release 或附件上传；之后用户另行授权打包 APK 并提交 GitHub，当前打包/发布记录见 `APP_RELEASE_PLAN.md`。

## 视觉目标与验收尺度

用户参考截图原尺寸 2461×1246，聊天显示约 2048×1037；红圈围绕东京名称。红圈是整行标题的目标占用范围，不是背景板、边框或精确字形轮廓。

- 在相近桌面宽高比、东京、到达高度约 250 km 的同视角，两个字整行可见字形宽度目标为视口宽度 **20%–24%**，中心目标 22%。相对现有截图约 4–5 倍，不能再只从 28px 增加几个像素。
- 用 CSS 视口与投影后的可见字形包围盒衡量比例，报告 CSS 像素和截图 DPR；不要把原图物理像素直接当 fontSize。采用约 200px 字形宽度/1000px 视口等同比例描述，最终以截图为准。
- 两三个中文短名以此尺度为基准；四字、英文、混排不强制拉伸到同一宽度。先确定与东京基准协调的字号，再执行长名称宽度限制。禁止横向变形字形或单纯拉大间距凑宽度。
- 桌面较长名字建议限制在视口约 55% 内，并服从真实工具栏安全边界；手机短名可用宽度约 45%–60%，长名最多实际安全宽度。允许 Sol 依据真实手机截图微调，记录最终规则。窄屏不能照搬桌面巨大 em。
- 计算到达视角下一次性世界尺寸，保持地理中心、地理朝向、曲面贴合及随相机自然缩放；禁止每帧固定屏幕尺寸或反向缩放。旋转/窗口变化仅按既有生命周期处理并验证，不引入每帧排版。

## 字体、颜色与动态

- 保留本地 Cinzel Medium 500 与思源宋体 Medium 500。中文约 0.08em、英文约 0.10em 的字距作为起点，主要通过字形本身放大增强；保留实际空格/中点/数字及混排布局修复，不人为转换大小写。
- 主色明确为 **浅香槟金 #F2DEAE**，取代当前浅灰绿 #E7EEEB。明亮影像/街道使用协调的深古铜候选 **#644A2B**，由实际样本验证并可小幅调整；这是主色的可读性配套，不另换视觉方向。
- 复用现有亮度提示与滞回，禁止新增地图请求或逐帧 GPU 读回。无背景板、明显黑描边或光晕。大标题覆盖范围较大，需观察整条文字跨明暗区域的实际对比，不能只凭中心采样或单张平色图声称处处清晰。
- 保留飞行最后约 1/3 显现，到达约3秒停留、0.5秒退出。渐隐以最终 fit 后到达尺寸为基准，默认从现有1.5倍到3倍起步；到达时完整可读，适度放大不立即消失，更近时平滑淡出。若大字超出视口，协调收尾阈值并记录取舍，不擅自改为常驻文字。
- 大字会覆盖更宽地表，需要实际验证曲面细分足够、边缘贴地、深度遮挡、中心稳定、背面隐藏与碰撞；必要时仅调整本文字层几何细分和相关算法，不能用关闭深度测试掩盖问题。

## Sol 实施记录（2026-10-14）

本轮源码、受控浏览器验证和共用前端同步已完成；最终观感尚未由用户确认。用户补充“东京只是示例，为所有搜索文字应用这种大字格式与颜色”，实现已覆盖每次搜索产生的地表名称，包括中文、英文、中英混排、长名、数字和坐标，没有按“东京”名称分支选用大字号。本文中的东京仅为尺寸校准样本。

### 实际尺寸与布局

- 新增 `src/layers/SearchTitleSizing.ts`：桌面到达 em 为 `min(视口宽×0.22/2.007, 视口高×0.42)`；宽度小于900的紧凑视口用0.52替代0.22。2.007来自当前思源宋体“东京”两个字的可见轮廓与0.08em字距，不能用两个全字宽或SDF四边形替代。所有名称共享该名义 em。
- 桌面整行最大宽度为视口55%，并服从实际工具栏安全宽度；紧凑视口的一至三个汉字最多60%，其余名称最多实际安全宽度。先压缩额外字距，再一次性等比缩小超长字形；不拉伸字形、不凑等宽标题。手机竖屏本次安全宽249 CSS px，横屏828 CSS px。
- 搜索时依据工具栏与标题的纵向重叠确定安全宽度，修复横屏顶部横向工具栏不必要地挤小标题的问题。到达世界尺寸只创建一次；缩放、斜视和视口变化保持同一地理位置、朝向、世界字号和fit，不重新排版。
- 字体保持本地 Cinzel Medium 500、思源宋体 SC Medium 500；Latin/Han/无空格跨脚本字距保持0.10/0.08/0.09em。搜索输入与列表UI、地图质量、相机飞行、自转、Logo未作调整。

### 颜色、曲面与收尾

- 最终主色 **#F2DEAE**，亮度提示选中的明亮影像与街道配套色 **#644A2B**。保留既有8×8缓存采样、3×3邻域和0.27/0.19滞回；无新增地图请求、描边、光晕或背景板。
- 暗森林样本为香槟金，街道样本为古铜。Sahara回放在手机z9中心亮度0.318时自动选古铜；桌面z10/z11中心亮度0.228/0.194时保留香槟金。测试记录实际提示与颜色，没有强行覆盖亮度判断。完整长行跨不同地形纹理仍有局部对比差异；当前中心邻域提示不能证明整条文字在所有真实底图上都同样清晰。
- SDF从64提高到128，单字网格细分从4提高到24，保留原WGS84 shader、2m锚点偏移与深度测试。实际GPU shader捕获16875个顶点，椭球最大残差0.000161m、最大单三角形弦高误差0.00581m；长名边缘曲面下弯约649.27m。前景遮挡验证的字形差异像素由26586降至0，未关闭深度测试。见 [surface-gpu.json](../artifacts/search-label-grand-title/surface-gpu.json)。这证明受测网格/遮挡计算，不代表地理影像绝对精度。
- 飞行最后约1/3显现，到达保持3秒并在0.5秒内退出；减少动态到达后显示、3秒直接移除。保留以最终fit到达字号为基准的1.5–3倍平滑渐隐，并增加极远距离隐藏。
- 新增可见轮廓投影安全渐隐：缓存字形实际轮廓边界，九个曲面采样点计算屏幕范围，距边缘/工具栏不足12px时平滑降低透明度。搜索与resize时更新工具栏矩形；不逐帧测DOM或重排。普通桌面长名1.5倍仍完整显示；已占满安全宽的手机长名1.05倍约0.57透明度、横屏长名约0.26，1.2倍已隐藏。这是保持世界尺寸同时避让控件的取舍，短名的连续缩放另由生命周期脚本验收。
- 竖屏标题旋转到横屏时，位置、朝向、scale与截止时间不变，实际字形更新次数为0；避让矩形正确变为顶部横排工具栏。
