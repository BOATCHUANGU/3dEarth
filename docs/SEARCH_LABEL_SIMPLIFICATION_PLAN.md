## 用户确认的效果

- 删除地球上全部预设地点的常驻点和名称，删除图层面板“地点标记 / 每一次相遇的坐标”及其开关。
- 搜索输入时只显示正常结果列表。选中城市后飞向目标，在目标位置显示一条简洁名称（例如“上海”）；轻柔淡入，飞行到达后停留约 3 秒，再淡出。
- 同时最多一条临时名称，再次选择地点替换上一条。不加信息卡、英文副标题、装饰圆点或常驻标记。首次打开、普通拖动与空搜索建议不主动显示地球标签。
- 默认自转降为当前速度的一半，暂停/继续、手动拖动、飞行和近地暂停的现有行为保持。
- 先完成并验证 Web，再同步 Android；本轮不进行 Android 设备/模拟器检验。

## 实现边界

1. 实施前 App 的图层配置含 markers，EarthRenderer 使用 MarkerLayer，CameraController 的 `autoRotateSpeed` 为 `0.12 * spin * spin`。已核对源码并删除旧图层，仅把自转基础系数减半为 `0.06`，保留原高度衰减；未改变云层漂移、太阳时钟或飞行动画速度。
2. 清理常驻标记 DOM、事件及相关配置/死样式。保留搜索五城建议、全球城市检索、坐标输入和返回首页。不得误删地点数据在搜索中的用途。
3. 临时名称跟随选中地点的屏幕投影，目标在背面或视口外时隐藏，不贴在屏幕边缘。窄屏避免裁切和遮住主要控件；标签不拦截点击/拖动，文本安全写入。
4. 从飞行到达后计算约 3 秒停留，避免长飞行期间提前消失。飞行取消、重置、下一次选择和销毁及时清理旧计时/动画，后台恢复不闪现过期标签。减少动态时跳过淡入淡出动画，仍显示短暂静态名称。坐标查询保留定位功能，不虚构城市名，使用紧凑经纬度表示。
5. 不改地图来源/网络/瓦片/清晰度、Logo、Android 原生启动或其他面板。必要内部实现由 Astra 判断，以保持改动集中为准。
