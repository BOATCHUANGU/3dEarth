# 3D 地球界面减法计划

> 状态：2026-10-04 已完成代码及文档调整，待 Sol 验证。按用户要求未运行构建、测试或浏览器验收；下列验收标准仍待执行。

## 目标

减少主视图上的常驻提示、技术状态和控制按钮，让地球成为视觉焦点，缩短用户从打开页面到开始探索的路径。允许移除低价值的快捷功能，但保留核心的地球旋转、缩放、地图来源选择、图层署名和错误恢复能力。

## 对照截图与处理方案

| 当前界面 | 计划调整 | 保留方式 |
|---|---|---|
| 底部「拖动旋转 · 滚动缩放」提示 | 从主视图彻底移除常驻提示及其占位 | 拖动、滚轮/双指和缩放按钮继续工作；如需说明，放在「星球档案」等次级帮助内容中 |
| 「Sentinel-2 · 10 m · Z7 · 高清加载 0/252」状态条 | 正常加载、成功、加载进度、来源名、分辨率、瓦片数和 LOD 不再覆盖地球显示 | 仅在地图确实加载失败且需要用户操作时，显示简短反馈与重试入口；不新增技术信息面板 |
| 底部「星球 / 区域 / 城市 / 街区」和「自动 / 卫星 / 街道」两组分段按钮 | 从主视图移除整条常驻快捷控制栏，减少遮挡 | 保留地图模式选择，迁入现有「图层设置」面板并清楚标注；移除尺度预设按钮，使用现有滚轮/双指和 +/- 控件连续缩放 |
| 页脚中的「观测系统已就绪」或「LOD 7 · 0/252」等运行状态 | 删除重复、面向开发诊断的常驻状态文案 | 保留 UTC 时间（若当前设计需要）和影像来源/许可入口 |

## 实施要求

1. 主场景保持简洁：移除 `interaction-hint` 与 `exploration-bar` 的可视元素及其对应 CSS，不留下空白占位。
2. 将 `自动 / 卫星 / 街道` 控件加入现有 `layers-panel`。继续使用已有地图模式状态和交互逻辑，保持选中态、键盘操作和 `aria-pressed`；用短标题（如「地图样式」），不要再增加解释段落。
3. 删除四档尺度预设快捷按钮及只服务于这些按钮的界面逻辑；不得删除滚轮/触控板/双指缩放、工具栏 +/-、重置视角或连续飞行能力。同步检查「星球档案」是否仍声称存在已移除的快捷预设。
4. 正常瓦片加载时隐藏 `detail-status`，不显示源名、缩放级别、分辨率、完成数或进度。只有瓦片加载失败且确需告知用户时才显示短句；重试功能仅在可重试的异常时出现。切源、完成、进度和离线保留影像等非阻断状态不做常驻提示。
5. 移除页脚重复的渲染/瓦片状态输出，避免 `render-status` 再展示 LOD 或瓦片计数。初始加载遮罩与整体应用启动失败提示不属于截图中的常驻状态，本次保留。
6. 必须保留活动影像来源的署名/许可信息及「影像来源与许可」入口；不因视觉减法删除第三方数据归属。
7. 清理删除控件后不再使用的 CSS、事件监听和状态更新，避免隐藏控件继续被当作唯一入口；不进行与本计划无关的地图网络、瓦片、渲染架构重构。

## 验收标准

- 初始和正常探索状态下，不显示拖动/滚动教学文字、瓦片来源/分辨率/LOD/进度长条或重复运行状态。
- 主视图不再有两组常驻分段控制；在图层设置中仍能切换自动、卫星和街道模式。
- 用户仍可用拖动旋转、连续缩放、缩放按钮及重置视角操作地球；相机到达原街区尺度仍可用连续缩放。
- 地图异常时提供短而明确的反馈及适用的重试入口；无异常时不显示状态提示。
- 影像归属与许可信息仍可查看，布局在窄屏上不遮挡主要地球画面。
- 同步修正文档中与被移除快捷入口矛盾的界面说明。

## 不在本次范围

- 更换地球底图或瓦片供应商、调整中国网络策略、改变地图缓存与加载算法。
- 删除图层、光照、时间、全屏等其他功能；后续如需进一步删减，另行提出计划。
- 新增引导流程、设置页、诊断面板或新的产品功能。
