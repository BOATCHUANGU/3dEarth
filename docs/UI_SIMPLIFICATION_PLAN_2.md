# 地球主视图居中与界面减法计划

> 状态：2026-10-04 已完成代码与文档实施，待验证。本轮按限定范围调整左侧内容栏、地球上方说明和右侧工具栏，未运行构建、测试或浏览器验收；下列验收标准仍待执行。

## 目标

把 3D 地球作为页面唯一主视觉：移除截图中左侧整块宣传与地点详情内容，删除地球上方的常驻说明，让地球视口回到页面中心，并把右侧图标操作收敛成清晰、轻量的一组控制。

## 本次实施范围

1. **移除左侧整块内容**：删除 `.intro`，包括口号、解释段落、当前地点名称/坐标/说明和「进入城市 · 高清探索」按钮。不要用另一块文字面板替代。
2. **移除地球上方说明**：删除 `.orbit-caption`，包括「地球观测站」和「模拟光照 · 10:30 UTC」；光照时间仍在现有光照设置中查看和调整。
3. **居中地球视口**：桌面及移动端均让 `#viewport` 覆盖 `.experience` 的主内容宽度，不再为左栏预留 21%–24% 空间；同步居中初始加载遮罩与启动失败遮罩。右侧工具栏作为浮层，不挤压画布宽度。近地视角也遵循相同中心轴。
4. **整理右侧控制**：保留放大、缩小、重置、图层、光照/时间和桌面全屏操作；将图标按钮统一尺寸、底色、边框、焦点和悬停状态，并按“视角”（+/-/重置）与“显示”（图层/光照/全屏）分组，中间只留克制的间距。压缩过高、过重的背景和阴影，使控制退到地球之后。
5. **清理失效布局与代码**：移除左侧内容和顶部说明专属的 CSS、响应式规则及事件/DOM 更新。地点列表卡片与搜索仍能选择地点并直接飞行；重置视角、地点标记、时区时钟、相机连续缩放、自转、地图样式、图层和光照功能继续可用。不要保留对已删除 `#fly-selected` 或地点详情节点的查询。
6. **同步项目说明**：README、`PROJECT_PLAN.md` 和星球档案中的操作说明不得再暗示主视图显示地点介绍卡或地球观测站状态条；保留许可和影像来源信息。

## 验收标准

- 左侧口号、描述、城市详情、坐标和“进入城市”按钮全部消失；主视图不再有左侧文案栏。
- 地球上方不再显示“地球观测站”或模拟光照状态文案。
- 桌面与窄屏的地球在主视口中水平居中；页面加载和错误遮罩也覆盖同一主视口，布局无左侧空白槽。
- 右侧按钮仍可聚焦、点击和通过键盘操作；标签/`aria-label` 清楚，分组容易辨认，手机布局不遮住地球主体或底部必要控件。
- 精选地点和搜索仍可定位/飞行；地点卡片选中态、重置、图层/地图样式、光照、自转和许可入口保持可用。
- 与删除内容相关的选择器、CSS 和事件处理已清理，没有空节点访问错误。

## 实施记录（2026-10-04）

- `src/app/App.ts`：删除 `.intro` 全部内容、`.orbit-caption` 和 `#fly-selected` 专用事件；去除地点详情节点及 `#light-mode` 的更新。目的地卡片的选中状态改由 `updateSelection()` 更新，继续调用原有定位、飞行和重置逻辑。
- 右侧工具栏使用两个带 `role="group"` 与名称的分组：“视角”含放大、缩小、重置，“显示”含图层、光照和桌面全屏。按钮 ID、可访问名称和现有操作事件保留。
- `src/styles.css`：删除左栏、地点详情、顶部说明及它们的近地/响应式规则；视口、加载遮罩和错误遮罩统一为 `inset: 0`，不再按断点为左栏预留空间。工具栏采用 40 px 独立按钮、4 px 组内间距和 12 px 组间距，统一底色、边框、悬停、展开与焦点状态；底部自转控制与主视口中心轴对齐。
- 更新星球档案操作说明、README 和 `PROJECT_PLAN.md`；同步后续 [UI 验证清单](./UI_SIMPLIFICATION_SOL_TESTS.md) 中的旧节点/入口要求。
- 保留目的地卡片、搜索与坐标定位、地点标记、时钟、许可与来源署名、地图/图层/光照、自转、缩放、重置和桌面全屏。地图数据、网络与渲染模块未修改；下方候选项仅作后续取舍。

## 待验证项

- 后续单独执行类型检查、构建及所需回归；旧浏览器脚本需先迁移已删除 DOM 的断言，不能恢复已删界面来通过脚本。
- 核对桌面、320/390/768 px 窄屏及短屏中的地球中心、加载/错误遮罩中心、右侧按钮与罗盘/底部控件间距，并确认键盘焦点与按钮操作。
- 核对目的地卡片、搜索坐标、标记飞行、重置、图层/地图样式、光照时刻、自转以及来源切换期间的署名。
- 本轮只实施并阅读源码清理关联，未生成新构建、测试结果或验收截图；历史记录不代表本阶段已通过验证。

## 后续可减法候选（不纳入本次实施）

以下是从当前页面代码中发现的候选项，先供产品取舍，不授权本轮一并删除：

| 候选 | 观察 | 可考虑的减法 | 保留时的理由 |
|---|---|---|---|
| 两个入口打开同一星球档案 | 顶部「星球档案」和页脚「影像来源与许可」都打开同一对话框 | 合并为一个入口，再在档案内保留许可链接 | 档案与数据许可对用户承担不同的信息任务，入口标签需避免混淆 |
| 罗盘 | 右上 N/S 罗盘是常驻装饰与方向提示 | 默认隐藏，交互时短暂出现，或在近地模式隐藏 | 可帮助用户判断旋转方向；如果用户依赖方向感应保留 |
| 高度读数 | 底部持续显示观测高度，数值会随缩放频繁变化 | 移除，或只在缩放过程中短暂显示 | 可提供当前比例尺上下文，地理探索时仍可能有用 |
| 自转按钮文案和波形 | 状态文字、暂停/播放图标和动画波形同时表达自转状态 | 第三阶段已改为仅显示暂停/播放的小按钮，去掉可见文字和常驻波形 | 自转是独立功能；保留图标状态和辅助技术可访问名称 |
| 图层面板解释文案 | 图层行有副标题，另有固定画质、超采样和各向异性说明 | 只保留可操作的图层名称，收起或删除实现细节描述 | 副标题能帮助首次使用者理解云层、夜光等效果 |
| 光照面板说明和预设 | 面板标题说明、段落、滑块、三个时间预设和底部注释同时出现 | 保留时间滑块和实时太阳，压缩标题/注释，评估是否需要两个预设 | 晨昏/夜间预设能提供快速观赏效果 |
| 精选目的地与搜索 | 精选地点入口和搜索都能导航；原搜索只匹配五个精选城市和坐标 | 第三阶段已删除首页目的地栏，把五个精选城市移入搜索建议，并以离线城市索引扩展到全球常见城市 | 搜索覆盖城市查询和坐标导航；城市栏被删除后的快捷发现由搜索建议承担 |

第三阶段已完成自转波形和精选目的地栏的减法，并将搜索扩展至离线全球城市索引。剩余减法候选可评估固定画质技术说明、罗盘和高度读数；罗盘与高度读数仍建议先观察实际使用价值，再决定是否隐藏。
