# 地球界面减法第三阶段：自转图标与全球城市搜索

> 状态：2026-10-04 已完成实现与数据生成，待验证。本轮未运行构建、测试或浏览器验收；实现记录和数据范围见文末。

## 目标与依据

继续减少主视图中的文字和重复入口：把地球自转状态收成一个小型图标按钮，移除主视图下方整块“下一站，世界”精选目的地栏，并将右上角搜索作为全球城市和坐标导航的统一入口。

实施前 `src/app/App.ts` 中的自转按钮同时显示暂停/播放图标、状态文字和动画波形；页面下方列出上海、东京、纽约、巴黎、悉尼五张目的地卡片；搜索只查这五个地点或识别经纬度。本轮复用已有按坐标飞行能力，不改写 Three.js 渲染或相机系统。

## 实施范围

### 1. 自转控件改为无可见文字的小按钮

- 将居中的长条控件收敛为小型图标按钮，只显示暂停或播放图标；删除“地球自转中 / 继续地球自转”可见文案和常驻波形动画。
- 保留原有暂停/继续自转行为、按钮禁用时序、`aria-pressed` 和屏幕阅读器可识别的动态 `aria-label`；不要用可见 tooltip 替代已删除的文案。
- 桌面、近地视角、窄屏及横屏下保持位置与地球中心对齐，不遮挡罗盘、缩放控件或主要地表。保留清楚的键盘焦点样式。
- 清理只用于长条、波形或文字的 DOM 更新和 CSS，不要删除自转偏好或相机自转功能。

### 2. 删除“下一站，世界”精选目的地栏

- 移除 `destination-section` 整块内容：中英文标题、五张城市卡片、序号、迷你地球缩略图和装饰箭头，并清理对应布局、响应式 CSS、卡片事件及选中态更新。
- 不再在首页为城市卡片留空位；地球视口应自然占据腾出的空间，不改变现有地球中心、相机或地图覆盖范围。
- 把上海、东京、纽约、巴黎、悉尼保留为搜索弹窗空查询时的少量快捷建议，复用其现有坐标与标签，避免删除后失去一键发现入口。建议用紧凑文字结果，不复刻原卡片和小地球。
- `locations.ts` 中被搜索和地点标记使用的数据仍需保留；只清除首页目的地栏专属代码。

### 3. 右上角搜索支持全球城市跳转

- 保留右上角搜索入口、`/` 快捷键、搜索对话框和现有坐标输入。城市名称搜索从五个精选项扩展到全球常见城市，中文名、英文/ASCII 名和可用的本地别名均可匹配。
- 优先使用随项目提供的离线城市地名索引（建议基于 GeoNames 全球 populated places 数据，按城市规模选择合适子集，并包含可用的中文/英文别名）。筛选只包括城市/有人居住的地点，不把搜索扩成街道地址或 POI 检索。该方案无需在运行时依赖中国境外地理编码 API 或高德 Key；城市结果即使在线地图源暂时不可用，也仍能查到并飞向正确坐标。
- 数据必须保持 WGS84 经纬度，记录数据集快照日期、筛选规则、许可和署名要求；在现有影像来源/许可入口或 `ASSETS.md` 加入 GeoNames 署名。数据文件按需延迟加载，并检查实际压缩体积，避免把庞大全球原始数据直接塞进主 JS 包。
- 对同名城市显示省/州与国家，避免用户选错；建议空查询展示不超过五个原精选城市。
- 选中城市后复用现有相机飞行，以城市区域视角落点（建议目标离地高度约 250 km），随后仍允许连续缩放至街区。经纬度输入继续保持当前行为，不因城市搜索改变。
- 城市地名索引只负责名称到坐标；地图瓦片来源、地区优先级和地图加载状态仍由现有网络/图层逻辑处理。中国网络是否能够加载某处卫星或街道瓦片不作为本功能搜索成功的条件。
- 本阶段不接入高德 Web 服务 API，也不抓取或拼接未公开的地图瓦片地址。当前应用使用多个地图来源；高德 Web 服务 API 条款对同时使用第三方地图服务有额外限制，除非已经得到与当前混合地图架构相容的明确授权，否则不要引入该依赖。GeoNames 全球地名数据提供 WGS84 坐标并要求署名，详见[数据说明](https://www.geonames.org/about.html)与[下载页](https://www.geonames.org/export/dump/)。

## 文档与兼容范围

- 更新 `README.md`、星球档案中的搜索说明和 `PROJECT_PLAN.md`，描述“搜索全球城市或输入坐标”，不要再引用首页精选城市栏。
- 不改变当前“中国网络优先 / 全球网络”设置、自动地区判断、天地图配置、影像/街道来源、瓦片调度、WGS84/LOD、昼夜着色或入场动画。
- 不引入地址/POI 搜索、历史记录页、账户、定位权限或新的地图供应商选择面板。

## 验收标准

- 地球自转控件是小型图标按钮，无可见状态文字和波形；暂停/继续、辅助技术名称、焦点与各断点布局正常。
- “下一站，世界”标题和整排目的地卡片从首页消失，腾出的版面没有空白占位；精选五城在搜索弹窗中仍可一键选择。
- 可用中文名、英文名及数据集中存在的别名搜索多个大洲的常见城市；同名结果可由行政区/国家区分。
- 选中城市后地球飞到城市区域尺度，之后可缩放；原有经纬度输入和 `/` 搜索快捷键仍正常。
- 关闭外网后，本地城市索引搜索仍可用；搜索不依赖高德、公共 Nominatim 或地图瓦片服务。瓦片离线时保留现有地图降级与错误反馈。
- GeoNames 署名和数据集来源可从现有来源/许可入口查看；记录索引文件及压缩后大小。
- 更新使用说明和总计划。本轮由 Astra 按用户要求实现；未授权的地图数据、既有地区选择或全球地图来源不受本计划影响。

## 本轮不做

- 不切换天地图/高德，不重写地图渲染，不增加外部地名服务凭据。
- 不删除自转功能、经纬度搜索、五个精选城市数据、坐标标记或相机飞行。
- 不运行构建、测试或浏览器验收；实现后将待验证项保留在文档中，另行安排验收。

## 2026-10-04 实施记录

- `src/app/App.ts`：自转按钮仅保留暂停/播放图标，动态维护 `aria-pressed` 与 `aria-label`，近地暂缓状态通过辅助技术名称说明；保留入场期间禁用时序。移除整块目的地栏、卡片事件、专属选中状态及更新方法；`locations.ts` 与地图标记保留。
- 空查询即时展示原五城紧凑建议，非空城市名触发离线 Worker 搜索。结果通过文本节点显示匹配别名、原名、一级行政区和国家；不把源数据插入 HTML。采用忽略大小写/变音符号的精确、前缀、包含匹配与行政区/国家组合条件，匹配级别优先、人口次序，最多 12 项。
- 城市搜索、五城建议与标记复用 `controls.focusOn()`，目标高度 250,000 m；坐标输入仍保持原 12,000,000 m 和范围检查，调试 API 的传入高度不变。
- `src/app/CitySearch.ts`、`city-search.worker.ts`：首次名称查询创建 Worker；索引读取、解压、规范化和检索在 Worker 内进行。输入防抖 140 ms，序列号避免旧结果覆盖新查询；关闭弹窗失效旧查询，dispose 清理 Worker 和未完成任务。提供索引加载提示/失败重试，空建议及坐标解析不等待索引。
- `src/styles.css`：删除目的地、迷你地球、波形及长条自转按钮的响应式样式；自转统一为居中 38 px 图标按钮及独立焦点样式；结果列表紧凑且可滚动。主视图通过原有 flex 布局占据移除栏目后的空间。
- 数据生成脚本 `scripts/generate-city-index.py` 使用官方 GeoNames cities15000、国家和一级行政区数据；源文件仅在生成时读取，未打包原始 dump。产物位于 `public/search/`，不静态导入主 JS。
- 本次 2026-10-04 获取快照包含 **31,729** 个居民点、**244** 个国家/地区代码；筛选为人口 ≥ 15,000 或 PPLC/PPLA，排除城市部分及废弃/历史/已毁居民点，坐标保持 WGS84。保留全部可用非空去重别名，但不保证所有城镇或所有中文/英文译名；便利别名字段无语言/历史标签，不作为官方译名判定依据。
- `cities.json.gz` 为 **3,473,691 字节（约 3.31 MiB）**；兼容回退 `cities.json` 为 **7,952,531 字节（约 7.58 MiB）**。正常从本应用读取 gzip，缺少 DecompressionStream 或压缩文件不可用时读取 JSON。元数据记录源 URL、Last-Modified、输入/产物哈希及字节数。
- GeoNames 官方 HTTPS 在本机握手失败，本次经同一官方域名的 HTTP 公共下载完成生成；无 API 凭据，未关闭 TLS 校验。来源记录与生成方式写入 `ASSETS.md`，GeoNames/CC BY 4.0 署名加入现有许可弹窗。
- 未修改网络配置、瓦片来源/请求、相机类、渲染着色、入场或 WGS84/LOD。离线指检索不依赖外部 API；没有新增 PWA/Service Worker，远程站点未缓存且完全断网时不能保证首次读取应用资源。
- README、星球档案和总计划已更新；本轮只完成代码编辑、数据生成及格式化，未执行应用构建或测试。完整待验证任务见 [UI_SIMPLIFICATION_3_SOL_TESTS.md](./UI_SIMPLIFICATION_3_SOL_TESTS.md)。
